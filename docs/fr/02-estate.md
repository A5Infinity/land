# 2. Estates composables

Des parcelles peuvent être regroupées en Estates afin de représenter une propriété composée. Le fingerprint permet de détecter toute modification de la composition.

Ce chapitre relie le mécanisme aux contrats concernés et explicite les invariants utiles à un intégrateur.
