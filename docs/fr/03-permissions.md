# 3. Permissions et opérateurs

Les opérateurs autorisés peuvent agir pour le propriétaire selon les règles du registre. Les intégrateurs doivent contrôler l’autorisation avant chaque transfert ou mise à jour.

Ce chapitre relie le mécanisme aux contrats concernés et explicite les invariants utiles à un intégrateur.
